# Supreme Warriors

Crusader Kings III mod. Version 1.5. Supported game version 1.20.*.

Player-only elite men-at-arms (foot + riders), muster decision, Mobility / Siege & Supply / Stand doctrines, Warriors' Banner aura while elites are on the roster, and an optional fourth archetype (archers / elephants / camels) via game rule.

Canonical working copy: `Documents/Development/CK3 Mods/Supreme Warriors`.
